# Amity University Bengaluru - Flutter Web App

A comprehensive Flutter web application for Amity University Bengaluru featuring a complete authentication system and dashboard interface.

## Features

- **Authentication System**
  - Login with email/password
  - User registration with form validation
  - Forgot password functionality
  - Password strength indicator
  - Remember me option
  - Form validation and error handling

- **Dashboard**
  - Personalized welcome greeting
  - University branding and information
  - Quick access cards for common functions
  - Announcements section
  - Responsive design

- **Navigation**
  - Side navigation drawer with categories
  - Top navigation bar with notifications
  - Breadcrumb navigation
  - User profile access

- **Firebase Integration**
  - Email/password authentication
  - User profile storage in Firestore
  - Real-time data synchronization
  - Secure authentication flows

## Technologies Used

- Flutter for cross-platform development
- Firebase Authentication for user management
- Cloud Firestore for database operations
- Material Design for UI components

## Getting Started

1. Clone the repository
2. Run `flutter pub get` to install dependencies
3. Ensure your Firebase project is set up correctly
4. Run the application using `flutter run -d chrome`

## Project Structure

- **lib/**
  - **main.dart** - Application entry point
  - **services/** - Firebase and other service integrations
  - **screens/** - Main application screens
  - **widgets/** - Reusable UI components
  - **utils/** - Utility functions and constants
